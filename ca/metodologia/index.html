    Per què existeix aquesta web

    Tots els centres públics i concertats de Catalunya han de tenir un projecte lingüístic: el document on el centre explica quin lloc dona a cada llengua. Són documents públics, però estan repartits en milers de webs, amb formats i noms diferents, i gairebé ningú no els llegeix.

    Aquesta web els recull, els llegeix tots amb els mateixos criteris i mostra, curs a curs de P3 a 2n de batxillerat, el paper que cada centre dona al català, al castellà, a l'anglès i a les altres llengües.

    L'objectiu és la transparència: que qualsevol persona pugui saber amb precisió com s'usen les llengües a les escoles i instituts de Catalunya, i comprovar-ho al document original. La web no valora ni opina: mostra el que diuen els documents.

    • 1La font és el document del centre

      Cada dada surt del projecte lingüístic que publica el mateix centre, no d'enquestes ni d'opinions.

    • 2Cada dada té la seva cita

      Al costat de cada dada hi ha la frase literal del document que la justifica. Si no hi ha frase, no hi ha dada.

    • 3Totes les llengües, igual

      Català, castellà, anglès i les altres llengües es llegeixen amb les mateixes categories i els mateixos criteris.

    D'on surten les dades

    • 2.936centres al cens
    • 2.074projectes lingüístics analitzats
    • 862centres no publiquen el projecte lingüístic
    1. 1

      La llista de centres

      Tots els centres de Catalunya amb segon cicle d'infantil, primària, ESO o batxillerat, del Directori de centres docents del Departament d'Educació (dades obertes, curs 2026/27): 2.936 centres, 2.296 públics, 578 concertats i 62 privats. Quins privats són concertats surt de les dades obertes de matrícula del Departament.

    2. 2

      Buscar el projecte lingüístic

      Un programa ha visitat la web de cada centre per trobar-hi el projecte lingüístic. Després, una persona ha revisat el resultat centre per centre: ha comprovat que el document fos el projecte lingüístic vigent del centre i, quan el programa no l'havia trobat, l'ha buscat a mà. Els documents es van descarregar entre octubre i novembre del 2026.

    3. 3

      Quan el centre no el publica

      Si la web del centre no té el projecte lingüístic, l'enllaç no funciona, el document no és el projecte lingüístic o no es pot obrir sense permís, el centre surt com a «No publica el projecte lingüístic» (862 centres). Ho decideix sempre una persona, mai el programa.

    4. 4

      Llegir el document

      Un model d'intel·ligència artificial llegeix cada document i omple una fitxa seguint un protocol escrit i públic: per a cada llengua i cada curs, el paper que li dona el document, i per a cada dada, la frase literal que la justifica.

    5. 5

      Comprovar la fitxa

      Abans de publicar-la, un programa comprova que cada cita sigui literalment al document i que la fitxa sigui coherent. Si falla, es refà. Els documents difícils els torna a llegir un model més potent.

    6. 6

      Calcular les xifres

      La web calcula els percentatges i les comparacions a partir de les fitxes, amb el mateix càlcul per a totes les llengües. Ningú no tria quins centres es mostren.

    Qui ha llegit els documents

    Els documents els ha llegit intel·ligència artificial, sota supervisió humana, principalment amb aquests models:

    • Claude Haiku 5.5 (Anthropic): 1.367 fitxes.
    • Claude Sonnet 5.5 (Anthropic): 590 fitxes, sobretot els documents difícils i les revisions.

    Per què te'n pots fiar: el model no pot afegir res que no sigui al document, perquè cada dada necessita una cita literal i un programa la verifica. Quan el document no diu una cosa, la fitxa diu «el document no ho diu», que la web mostra separat de «no s'ensenya».

    Les instruccions que va rebre el model

    Llegiràs el projecte lingüístic d'un centre educatiu de Catalunya. El que escriguis es publicarà amb el nom del centre: l'únic que importa és l'exactitud.

    1. Registra només el que diu el document. No dedueixis, no interpretis intencions i no completis res que no hi consti. Si el document no parla d'una cosa, indica que no consta: no és cap error.

    2. Cada dada ha d'anar amb la frase del document que la justifica, copiada literalment.

    3. Tracta totes les llengües igual. Català, castellà, anglès, altres llengües estrangeres i llengües familiars de l'alumnat es descriuen amb les mateixes categories i els mateixos criteris. Cap llengua no té apartats propis.

    4. Per a cada llengua i cada curs, de P3 a 2n de batxillerat, indica el paper més alt que li dona el document: llengua de les classes, llengua d'alguna matèria, assignatura de llengua, optativa, presència ocasional, no s'ensenya o el document no ho diu.

    5. Recull també en quines llengües es comunica el centre amb les famílies, quines llengües es fan servir fora de l'aula, quines llengües parla l'alumnat a casa si el document en dona dades, i qualsevol norma que tracti diferent les persones segons la llengua que fan servir, afecti la llengua que afecti. Descriu els fets sense qualificar-los.

    6. No comparis ni valoris les llengües entre elles: les comparacions les fa després la web, amb el mateix càlcul per a totes.

    7. Davant del dubte, registra el mínim que el text sosté, sigui quina sigui la llengua, i explica el dubte.

    Com ho pots comprovar

    • A la fitxa de cada centre, el botó «Projecte lingüístic» obre el document original.
    • «Veure les cites del document» mostra la frase literal de cada dada.
    • Un clic a qualsevol xifra o gràfic mostra la llista de centres que hi compten, amb les seves cites.
    • Tots els documents originals, amb el text extret, són en un repositori públic: github.com/Observatori-Linguistic/observatori-linguistic-documents. El codi de la web i les dades també: github.com/Observatori-Linguistic/observatori-linguistic-website.

    Què es mesura

    Per a cada llengua, curs a curs, el document li dona un d'aquests papers. Es guarda el més alt que s'hi esmenta.

    • Llengua de les classes

      S'hi fan les classes: és la llengua en què s'aprèn tot.

    • Llengua d'alguna matèria

      A més de la seva assignatura, alguna matèria no lingüística es fa en aquesta llengua.

    • Només assignatura de llengua

      Té un horari propi com a assignatura de llengua, per a tot el grup, i res més.

    • Optativa

      Assignatura que l'alumnat pot triar: no la fa tothom. Sobretot, la segona llengua estrangera a l'ESO.

    • Presència ocasional

      Hi apareix sense horari propi: contes, cançons, rutines.

    • No s'ensenya

      El document descriu el curs i no li dona cap paper.

    • El document no ho diu

      El document no en parla. No és el mateix que «no s'ensenya».

    Més detalls

    Quatre etapes, quinze cursos

    Seguim cada llengua des de P3 fins a 2n de batxillerat: infantil (P3–P5), primària (1r–6è), ESO (1r–4t) i batxillerat (1r–2n). Cada centre es mostra només amb les etapes que fa segons el Departament d'Educació, i cada gràfic compta només els centres que fan aquell curs. Molts centres que fan de P3 a 4t d'ESO tenen un document que només parla d'infantil i primària: llavors l'ESO surt com a «el document no ho diu». La formació professional no hi és.

    La segona llengua estrangera

    La quarta fila recull qualsevol llengua estrangera que no sigui l'anglès i que el centre ensenyi dins l'horari: francès, alemany, italià… A l'ESO sol ser optativa: l'alumnat la tria i no la fa tothom. Les activitats extraescolars no hi compten. Si un centre n'ofereix més d'una, la fila mostra el paper de la més present i la fitxa del centre les anomena totes.

    La comunicació amb les famílies

    Es registra en quines llengües es fan les comunicacions escrites habituals, en quines només una part (per exemple, només la web o alguna circular), en quines es poden obtenir per escrit si la família ho demana, quines només de paraula, i si hi ha traductors o mediadors per a altres llengües. La web ho mostra llengua per llengua, amb les mateixes categories per a totes.

    La llengua de l'alumnat

    Molts centres descriuen al seu projecte la llengua que parla l'alumnat a casa. Ho fan de maneres diferents: llengua familiar, llengua materna, origen o nacionalitat, i amb dades d'anys diferents. Només comparem les xifres de llengua familiar o materna, i sempre centre per centre, amb el que mesura i de quin any és. Quan les respostes de l'enquesta són múltiples, les xifres s'ajusten perquè sumin 100.

    Les diferències de tracte

    L'anàlisi registra, afectin la llengua que afectin, les normes o pràctiques del document que tracten diferent les persones segons la llengua que fan servir o que en limiten l'ús. Es descriuen sense qualificar-les i amb la cita literal. Només ho recullen els centres analitzats amb la segona versió del protocol.

    Per què el paper i no les hores de classe

    Les hores setmanals semblen la mesura natural, però no serveixen. A infantil no n'hi ha, perquè l'etapa és globalitzada i no té assignatures. A primària i a l'ESO les fixa el currículum igual per a tots els centres, així que no són una decisió del centre. El paper de cada llengua a cada curs sí que el decideix el centre i consta en el seu document. I distingeix el que les hores amaguen: no és el mateix una llengua en què s'aprenen matemàtiques que una que només té la seva classe de llengua, ni un conte a P3 que una assignatura amb horari propi.

    Públics, concertats i privats

    D'entrada, totes les xifres es calculen només amb els centres públics. Els botons «Públics», «Concertats» i «Privats» del menú «Centres» de la capçalera permeten afegir-hi o treure'n cada tipus, sempre amb un com a mínim, i la web recorda la tria. El cens oficial només distingeix entre públics i privats. Un centre privat es considera concertat si té algun ensenyament concertat (infantil, primària, ESO o batxillerat), segons les dades obertes de matrícula del Departament d'Educació (curs 2025/26), i privat si no en té cap.

    Els percentatges

    Cada percentatge és sobre els centres analitzats del lloc que fan l'etapa o el curs de què es parla, i sempre va amb el nombre de centres. Amb menys de 5 centres analitzats no se'n donen. Les xifres de Catalunya són les dels municipis que ja són a l'observatori.

    Què vol dir l'estat de cada centre

    Cada centre del cens està en un d'aquests dos estats:

    • Analitzat

      Hem llegit el seu projecte lingüístic i la fitxa en mostra les dades, amb les cites.

    • No publica el projecte lingüístic

      Una persona n'ha revisat la web i no hi ha trobat el projecte lingüístic publicat: no hi és, el document enllaçat no és el projecte lingüístic o no es pot obrir sense permís.

    Què no diu aquesta web

    • Mesura el que diu el document, no el que passa a l'aula. Un projecte lingüístic és una declaració d'intencions del centre.
    • Que el document no parli d'una llengua no vol dir que no s'ensenyi. Per això «el document no ho diu» es mostra separat de «no s'ensenya».
    • Hi ha documents antics. Cada centre mostra la data del seu. De quan són els documents.
    • Que un centre no publiqui el projecte lingüístic no vol dir que no en tingui: pot tenir-lo i no fer-lo públic.
    • El paper indica pes, no minuts: «només assignatura» no diu quantes hores té aquesta assignatura.
