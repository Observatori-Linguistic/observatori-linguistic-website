    Privacitat

    Què passa amb les teves dades quan visites aquesta web.

    Qui fa aquesta web

    És un projecte independent i de codi obert d'anàlisi de dades, fet amb la documentació pública dels centres educatius. Els documents, les dades i el codi són públics a GitHub. No està vinculat a cap administració, centre, partit ni organització, i no té ànim de lucre.

    Per a qualsevol qüestió sobre aquesta pàgina o sobre les teves dades, pots obrir una incidència a GitHub o .

    Quines dades es recullen

    Per fer servir la web no cal registrar-se ni donar cap dada. La web no té formularis ni comptes d'usuari.

    El navegador desa, només al teu dispositiu, l'idioma triat i el filtre de tipus de centre. Aquesta informació no s'envia enlloc.

    Estadístiques de visites, sense galetes

    Per saber quantes persones fan servir la web i quines pàgines miren, fem servir Cloudflare Web Analytics. No instal·la galetes, no desa res al teu dispositiu i no identifica ningú: només dona xifres agregades (visites, pàgines, país, tipus de dispositiu i d'on arriba la visita). Per això no veuràs cap avís de galetes.

    Si no vols que es compti la teva visita, pots bloquejar el domini static.cloudflareinsights.com al navegador o amb un bloquejador de continguts; la web funciona igual.

    La web no fa servir Google Analytics ni cap eina de publicitat.

    Allotjament

    La web s'allotja a Cloudflare Pages. Com qualsevol servidor web, Cloudflare tracta l'adreça IP de les visites per servir les pàgines i protegir-les d'atacs.

    Els teus drets

    Pots demanar accedir a les teves dades, rectificar-les o suprimir-les escrivint per les vies de dalt. També pots presentar una reclamació a l'Agència Espanyola de Protecció de Dades (aepd.es).
