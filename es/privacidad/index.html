    Privacidad

    Qué pasa con tus datos cuando visitas esta web.

    Quién hace esta web

    Es un proyecto independiente y de código abierto de análisis de datos, hecho con la documentación pública de los centros educativos. Los documentos, los datos y el código son públicos en GitHub. No está vinculado a ninguna administración, centro, partido ni organización, y no tiene ánimo de lucro.

    Para cualquier cuestión sobre esta página o sobre tus datos, puedes abrir una incidencia en GitHub o .

    Qué datos se recogen

    Para usar la web no hace falta registrarse ni dar ningún dato. La web no tiene formularios ni cuentas de usuario.

    El navegador guarda, solo en tu dispositivo, el idioma elegido y el filtro de tipo de centro. Esta información no se envía a ningún sitio.

    Estadísticas de visitas, sin cookies

    Para saber cuántas personas usan la web y qué páginas miran, usamos Cloudflare Web Analytics. No instala cookies, no guarda nada en tu dispositivo y no identifica a nadie: solo da cifras agregadas (visitas, páginas, país, tipo de dispositivo y de dónde llega la visita). Por eso no verás ningún aviso de cookies.

    Si no quieres que se cuente tu visita, puedes bloquear el dominio static.cloudflareinsights.com en el navegador o con un bloqueador de contenidos; la web funciona igual.

    La web no usa Google Analytics ni ninguna herramienta de publicidad.

    Alojamiento

    La web se aloja en Cloudflare Pages. Como cualquier servidor web, Cloudflare trata la dirección IP de las visitas para servir las páginas y protegerlas de ataques.

    Tus derechos

    Puedes pedir acceder a tus datos, rectificarlos o suprimirlos escribiendo por las vías de arriba. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (aepd.es).
