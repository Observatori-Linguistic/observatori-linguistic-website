# Llicència de les dades

Les dades elaborades per l'Observatori Lingüístic Escolar (els fitxers `cerca.json`,
`dq-ca.json`, `dq-es.json` i `p/*.json`, i les xifres, classificacions i textos de
les pàgines) es publiquen amb llicència **Creative Commons Reconeixement 4.0
Internacional (CC BY 4.0)**: https://creativecommons.org/licenses/by/4.0/deed.ca

Es poden reutilitzar, també amb finalitat comercial, citant «Observatori Lingüístic
Escolar».

Les cites literals són fragments dels projectes lingüístics que publiquen els
centres, i els drets d'aquests documents són dels seus autors.
